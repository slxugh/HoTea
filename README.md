# 🧋 HoTea
Информационная система для магазина чая
## 🧰 Использованный стек технологий
- C# WPF .NET Framework 4.8
- MS SQL Server 2022
- Entity Framework
- ClosedXML - Для экспорта в формате Excel
- DocX (Xceed.Words.NET) - Для экспорта в формате Word
- iTextSharp - Для экспорта в формате PDF
## 🗃️ Сущности информационной системы
1. Клиенты
2. Заказы
3. Товары в заказе
4. Поставщики
5. Чаи
6. Типы чая
7. Филиалы
8. Акции
9. Отзывы
10. Сотрудники
## ⚙️ Функционал информационной системы
- Авторизация пользователей ( Роли: Администратор и Менеджер | Пароли хранятся в хеше SHA512 )
- Создание, изменение и удаление записей в таблицах
- Поиск по всем атрибутам в таблицах
- Подсчет записей в таблицах
- Применение акции в таблице заказы
- Автоматический подсчет общей суммы заказа и суммы каждого товара в заказе
- При добавлении товара в заказ, проверяется наличие на складе введенного количества товара
- Ограничение на удаление связанных данных
- Создание отчетов о продажах в форматах Excel, Word, PDF
- Добавление, изменение и удаление пользователей информационной системы
